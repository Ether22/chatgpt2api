# 当前导入素材按身份共享，已提交轮次保留独立快照

依据用户本次明确需求，一个登录身份只维护一份可编辑的当前 MD 和一组参考图，供该身份的所有生图会话共享；不采用每个会话保存一套可变导入区的方式，以满足换会话、刷新和换浏览器后继续使用当前素材的要求。

已提交轮次拥有独立配置及有序参考图快照，后续替换 MD、修改参考图、清空导入区或删除另一会话，都不能改变这些快照。当前素材与轮次快照必须分别管理生命周期，因此“只保留一套当前素材”不等于删除旧轮次仍依赖的参考图。

本记录确认领域归属与生命周期边界，不表示已实现。同名条目的会话归属见 [0002](0002-conversation-scoped-source-entries.md)。
