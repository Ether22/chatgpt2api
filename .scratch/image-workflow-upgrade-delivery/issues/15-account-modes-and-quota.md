# 15: 监控、禁用与可消费额度

**What to build:** 在现有账号编辑界面选择正常、监控或禁用；监控组排最前，监控/禁用继续维护但不消费，额度准确区分。

**Blocked by:** None (can start immediately).

**Status:** integrated-and-verified

**Parent:** [生图工作流、服务端历史与账号管理规格](../../image-workflow-upgrade/spec.md)

**User stories:** US99、US101、US102、US103、US104、US105、US106。

- [x] 三种使用状态互斥，后台/手动刷新不改用户选择；监控和禁用持续刷新、监测和保活。
- [x] 全部生图、文本、搜索消费路径及可用能力判断排除监控/禁用，不只过滤图片入口。
