# 04: 普通参考图生成与独立快照

**What to build:** 普通上传保存一次参考图，通过文件引用生成；每轮记录自己的有序参考图快照，后续更改输入不改变旧轮次。

**Blocked by:** [03: 普通生图在服务器保存并跨浏览器恢复](03-server-conversation-roundtrip.md).

**Status:** integrated-and-verified

**Parent:** [生图工作流、服务端历史与账号管理规格](../../image-workflow-upgrade/spec.md)

**User stories:** US11、US48、US49、US88、US89、US90。

- [x] 输入文件选择及时反馈，上传完成后可提交普通编辑生图，多张结果不重复向服务器上传同一文件。
- [x] 每轮可读取原 Prompt、配置和有序参考图；换浏览器仍可查看参考图预览。
- [x] 素材引用独立于可变输入，释放输入引用不删除仍被轮次使用的文件；首次建立引用释放与清理能力。
- [x] 隔离身份的文件不能作为其他身份的参考图；上游文件复用遵循真实账号与协议边界。
