# 05: 同会话排队、并发、恢复与失败详情

**What to build:** 普通及参考图轮次可独立提交，账号池动态调度；忙碌可等待、重启可恢复，失败图片显示真实原因和可复制详情。

**Blocked by:** [04: 普通参考图生成与独立快照](04-reference-upload-and-snapshots.md).

**Status:** implemented

**Parent:** [生图工作流、服务端历史与账号管理规格](../../image-workflow-upgrade/spec.md)

**User stories:** US4、US5、US6、US7、US9、US10、US11、US12、US95、US96、US97、US98。

- [x] 同会话不同轮次不互相串行，实际消费由账号池容量决定，不写死账号数或生图槽位。
- [x] 忙碌或有明确恢复时间时等待，无合格账号或未知恢复时间时显示可重试错误。
- [x] 只续跑确定未发送的持久任务；已发送但未知结果先核实，不盲目重发，关闭页面后服务器仍负责已接受任务。
- [x] 超时、额度、无账号、读图与程序错误保留逐图状态及任务 ID，同轮同类通知合并，详情脱敏且可复制。
- [x] 轮询与保存只更新变化数据，页面仍可操作；可控上游验证重启和并发，无须消费真实额度。
