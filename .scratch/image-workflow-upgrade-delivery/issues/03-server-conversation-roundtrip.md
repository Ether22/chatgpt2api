# 03: 普通生图在服务器保存并跨浏览器恢复

**What to build:** 从普通纯 Prompt 提交到结果展示形成服务器闭环；同身份换浏览器能恢复当前对话和轮次，其他身份无权读取。

**Blocked by:** None (can start immediately).

**Status:** integrated-and-verified

**Parent:** [生图工作流、服务端历史与账号管理规格](../../image-workflow-upgrade/spec.md)

**User stories:** US9、US51、US52、US88、US89、US90、US93、US94。

- [x] 没有当前对话时并发提交只创建一个目标，网络重试不重复创建同一轮次或任务。
- [x] Prompt、配置、来源条目、轮次和任务归属先保存成功再消费；保存失败无上游请求。
- [x] 结果原图、缩略图、任务与会话读取都校验身份，页面以服务器数据为准，不迁移旧浏览器历史。
- [x] 受管理历史不被过期或低磁盘自动删除；无法保存时消费前提示。使用临时真实存储和可控上游验证完整提交/恢复路径。
