# 06: 共享 MD 与参考图导入区

**What to build:** 新增双栏导入弹窗，同身份跨会话和浏览器维护当前一份 MD 与参考图，支持追加、直接替换 MD 和手动清空。

**Blocked by:** [04: 普通参考图生成与独立快照](04-reference-upload-and-snapshots.md).

**Status:** implemented

**Parent:** [生图工作流、服务端历史与账号管理规格](../../image-workflow-upgrade/spec.md)

**User stories:** US36、US37、US38、US39、US40、US41、US42、US43、US44、US45、US46、US47、US48、US49、US50。

- [x] 两栏可点击和拖拽，普通上传入口保留；文件、数量、进度和错误及时显示，长列表/窄屏可滚动。
- [x] 新 MD 仅替换 MD，图片追加，同名明确拒绝静默覆盖；关闭、生成和刷新不自动清空。
- [x] 清空只释放当前素材引用，保留在途或历史快照；不产生多套导入素材历史。
- [x] 过期版本的替换/修改/清空提示冲突，无冲突新增可合并；另一浏览器能恢复当前状态。
- [x] 本票独立验收素材管理；下一票在此弹窗增加条目解析与匹配预览。
