# 17: 账号只保留不物理删除

**What to build:** 移除手动账号删除能力，异常/限流保留账号并更新状态，旧请求和旧配置不能绕过保留规则。

**Blocked by:** None (can start immediately).

**Status:** integrated-and-verified

**Parent:** [生图工作流、服务端历史与账号管理规格](../../image-workflow-upgrade/spec.md)

**User stories:** US110、US111。

- [x] 账号编辑/列表的单个、批量、移除异常等手动删除入口消失。
- [x] 旧 DELETE 明确拒绝，不假装成功；旧自动删除配置及对应设置入口不再生效。
- [x] 刷新、登录失败、生图、文本和搜索等异常路径均保留账号，包含绕过共用删除入口的直接移除路径。
- [x] 使用真实持久存储与受控异常验证账号仍可查询/维护，不误改用户密钥等其他对象的删除语义。
