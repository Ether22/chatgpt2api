# 08: 选择 MD 条目并随上传进度生成

**What to build:** 用户选择部分有效条目、设置批量或单条数量后在当前会话生成；每条自己的参考图就绪即开始，不等整份上传。

**Blocked by:** [05: 同会话排队、并发、恢复与失败详情](05-concurrent-queue-recovery-errors.md)；[07: MD 结构解析、匹配预览与纠错](07-md-preview-validation.md).

**Status:** integrated-and-verified

**Parent:** [生图工作流、服务端历史与账号管理规格](../../image-workflow-upgrade/spec.md)

**User stories:** US8、US9、US23、US24、US28、US31、US32、US34、US51、US52、US53、US54、US55。

- [x] 只提交已选有效条目，未选/跳过条目无消费且不出现在结果区或导航占位。
- [x] 批量数量与单条覆盖均为 1–100 整数，沿用记忆的选择；模型和画质按提交时编辑框保存。
- [x] 某条就绪并持久保存归属后先生成，其他条目仍上传；结果关联文档名称、标识、输出名及独立快照。
- [x] 同会话同标识在换 MD 或清空后延续原来源，旧轮次不被更新；新对话同标识独立。
- [x] 缺省输出名可辨认，缺省尺寸或缺图不能生成；接口与浏览器验证选择到结果的完整路径。
