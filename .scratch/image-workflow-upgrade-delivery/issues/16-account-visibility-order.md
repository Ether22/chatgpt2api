# 16: 账号隐藏与组内拖拽排序

**What to build:** 用户可隐藏账号并找回，在监控组和其余账号组内部拖拽排序，刷新或重开后保持顺序。

**Blocked by:** [15: 监控、禁用与可消费额度](15-account-modes-and-quota.md).

**Status:** integrated-and-verified

**Parent:** [生图工作流、服务端历史与账号管理规格](../../image-workflow-upgrade/spec.md)

**User stories:** US100、US105、US107、US108、US109。

- [x] 隐藏独立于正常/监控/禁用，默认不展示，可显示隐藏账号并取消隐藏。
- [x] 隐藏不改变消费资格、额度刷新、统计或原有导出；找回后按所属组和保存顺序出现。
- [x] 两组只能各自内部排序且监控组始终在前，令牌刷新不改变保存位置。
- [x] 通过两种使用状态、隐藏组合及跨刷新保存验证完整列表行为。
