# 18: 业务 API、界面、日志及文件日期统一北京时间

**What to build:** 用户跨图片、账号、用户密钥、日志和备份看到一致的北京时间，文件日期也一致，协议 UTC 与瞬时计算正确。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

**Parent:** [生图工作流、服务端历史与账号管理规格](../../image-workflow-upgrade/spec.md)

**User stories:** US112、US113、US114。

- [ ] 业务输出和前端展示不依赖环境默认时区，日期带有无歧义语义；检查午夜边界及不同浏览器/服务器时区。
- [ ] 图片及任务、账号、用户密钥、日志、备份和关联业务文件均覆盖，不只改一个格式化函数。
- [ ] JWT、签名、外部协议 UTC 和内部耗时计算不被机械加八小时；不引入旧日期迁移。
- [ ] 所有新票也遵循该已确认时间规则；本票修复已有业务链路，通过接口、文件与浏览器观察验证。
