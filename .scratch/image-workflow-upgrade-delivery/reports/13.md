## 行为与接口

- `GET /api/image-conversations?offset=0&limit=30` 默认30、最多100条，只返回会话元信息、`turnCount`、`stats`、空 `turns`、当前会话 ID 及 `pagination`，不展开历史图片。顶层 `stats` 为当前身份的全局计数。
- `GET /api/image-conversations/{id}` 默认每页2轮、最多10轮，默认定位最新的对齐页；轮次完整保留，100张的一轮不拆散。`pagination` 包含 `offset/limit/total/next_offset/previous_offset`。密集场景实测后经主任务确认，将默认值从5轮降为2轮。
- 同一路径支持 `turn_id` 或 `image_id` 定位指定目标所在页，并返回 `target`；`navigation=true` 返回当前页的轮次／来源／图片 ID 和状态，不含 Prompt、参考图及图片内容 URL。每次重新校验身份。隐藏结果或已忽略图片不能通过目标定位重新出现；双隐藏轮次不出现在导航项中。
- `GET /api/images?offset=0&limit=12&tag=...` 默认12、最多100项；身份、日期、标签及参考图排除在分页前完成。响应包含当前页 `items/groups` 和 `pagination`。`paths_only=true` 仅返回相对路径，用于用户明确点击的“全选结果”；每批100项，显示进度、可取消，失败保留已选项目，可再次执行恢复。
- 侧栏每批30条，主动继续加载；结果区域只保留当前会话的一页详情，支持较早／较新／最新页。轮询只更新首批元信息与当前详情页；首批成员或总数变化时重置续页，避免删除或排序变化后漏掉记录。异步读取使用版本防止旧响应覆盖新选择。
- 回到旧会话时恢复页偏移和阅读位置。浏览器仅保存数值偏好；最多400张已见图片的数值宽高驻留内存以稳定占位。结果图离开视口预加载区域后释放 Blob，返回时重新读取。删除模块级 Base64／Blob 缓存，图库换页也释放旧 Blob。
- 图库列表从既有 JSON 索引读取，不再每次 GET 执行目录对账、过期清理或逐图 stat。图库、空间统计及受保护原图／缩略图／单图下载的同步 I/O 使用现有线程池入口。
