## 公开契约（供 08 使用）

`GET /api/image-imports` 及已有素材修改响应增加：

- `md_version`：当前 MD 的代号，只在成功替换/清空时变化。素材 `version` 仍遵循 06 结构修改并发规则，`revision` 每次保存递增。
- `candidates[]`：`key`、`config`、`skipped`、`status`、`errors[]`、`matches[]`。
- `key = md_version:章节行号` 与 `config.document_id` 分离；重复文档标识对应独立行，可分别纠错，不折叠覆盖。
- `config = {document_id, name, prompt, size, output_name, reference_names}`。尺寸为明确目标 `宽x高`；输出名可为 null。`reference_names=null` 缺声明，`[]` 显式无图，否则为严格文件名有序列表。
- `errors = [{field, code, message}]`；结构错误、缺文件、同名冲突逐条可见，重复文档标识每行均报错。只有未改字段的解析错误持续保留，纠错字段重新校验。
- `matches = [{name, status, upload_id, reference}]`，顺序与声明一致，ready 时 reference 为 06 服务器图片引用。
- `status=ready` 表示配置有效且本条所有参考已保存；`pending` 表示配置有效且所需文件均已登记但至少一个尚无已保存 reference；`error` 为结构/匹配错误。跳过独立于 status，不强制有效。清理 intent 期间提交读取由现有 `_check` 拒绝。

`PATCH /api/image-imports/candidates/{key}`：请求 `{request_id, version, md_version, changes}`。只接受 `document_id/name/prompt/size/output_name/reference_names/skipped`；修改后持久保存并返回完整同源预览。过期素材/MD 409；不存在候选 404；类型及非法字段 400/422；磁盘失败 507。同 request_id+同内容可重放，异内容拒绝；changes 按排序紧凑 UTF-8 JSON 的 SHA-256 保存回执，回执不存旧 Prompt 全文。

`ImageImportService.validated_candidates(identity, version, md_version, keys, *, allow_pending=False)` 是 08 的服务端规范读取入口。当前 metadata 锁内检查版本、身份、候选存在性、跳过、结构错误和就绪状态，并返回 `{version, revision, md_version, candidates}` 的独立配置副本。`allow_pending=True` 仅允许已登记尚未就绪的参考，不允许缺图/错误/跳过；每个匹配都带上传 request_id，供 08 建立等待与参考快照。默认只允许 ready。08 必须自行持久保存和 pin 不可变快照再消费，本票不 pin、不建生成轮次，不把裸 Prompt 当校验凭据。

MD 替换重建候选 key 与配置，清空移除候选；追加参考或完成上传不重建候选，所以纠错与跳过保留。同身份跨会话/浏览器读取仍为同一套当前素材。
