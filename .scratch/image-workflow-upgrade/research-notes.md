## 第一轮确认记录（2026-09-08）

本节为用户已确认结果；早先建议与本节冲突的部分不再适用。

| 问题 | 用户答复与有效结论 |
| --- | --- |
| Q1 条目延续 | 同一会话同标识默认原条目，清空素材也不另建来源；新产品由用户自己新建对话。详见 ADR 0002。 |
| Q2 队列与重启 | 按推荐：忙碌或有明确恢复时间则排队；无合格消费账号报可重试错误；重启续跑确定未发送的任务，已发送但未知的先核实。 |
| Q3 范围删减 | 用户会重新部署，不需要任何旧历史迁移或认领功能；已从实施需求中移除。 |
| Q4 同时修改 | 按推荐：过期版本操作提示冲突，不静默覆盖；无冲突新增可合并，同名文件报错。 |
| Q5 实际尺寸 | 显示实际尺寸即可，不提示与 MD 不一致，也不要求下载精确匹配。MD 仍必须提供有效请求尺寸。 |
| Q6 解析歧义 | 按推荐：冲突/缺声明时报错，可补齐或跳过；明确无参考图才允许无图生成；不自动拼接全局说明。 |
| Q7 历史保留 | 按推荐：当前素材、快照和新图库历史都只手动删除；磁盘不足提前阻止无法保存的生成，不自动删除历史。 |
| Q8 账号状态 | 用户修正：监控与禁用互斥，不能同时选择；监控继续维护但不消费、不计入可用剩余额度，监控组排在最前。隐藏仍是独立展示状态。 |

## 第二轮确认记录（2026-09-08）

### Q9 禁用账号的后台维护

用户选择：“继续后台维护，只停止生图、文本、搜索等消费”。

有效规则：禁用继续自动额度刷新、状态监测和保活，但不参与消费，也不计入可用剩余额度；后台刷新和手动刷新都不能解除使用状态。监控与禁用互斥，隐藏保持独立；监控组排序和监控额度单独统计规则不变。

“禁用停止自动维护”的早先建议未被采纳，不得实现。
