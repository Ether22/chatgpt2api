# 03 生成流水线、队列与失败详情

状态：待实施，仅文档。规格：[R02、R07、R12](../spec.md)。依赖：01；MD 接入依赖 02。

## 工作范围

- 去除前端会话级串行限制，各轮次独立提交；复用账号池实时资格与容量等待，不增加固定生图槽位。
- 已选有效条目的参考图准备完成且服务器归属/快照保存成功后，才允许对应任务消费；其余条目继续上传。
- 账号忙或有明确恢复时间时排队；无合格消费账号或无已知恢复时间时返回可重试的真实原因。
- 已保存未发送任务在重启后续跑；已发送结果未知的先核实，不盲目重发。关闭页面后已接受任务仍由服务器负责。
- 复用已上传文件引用；区分到服务器和到上游的上传，基于实际账号/协议约束判断可复用范围，避免错误地共享账号私有上游文件标识。
- 保留现有结构化错误分类，贯通任务、接口与前端的脱敏详情、任务 ID 和复制能力；同轮同类错误合并通知，逐图状态仍独立。
- 保存与轮询只更新变化数据，耗时 I/O 不占用页面或服务器事件循环；测量各阶段耗时而非只加加载动画。

## 验收

- 同会话两个轮次可同时进入账号池，动态增减可用账号无须改固定槽位；监控/禁用不被分配消费。
- 注入保存失败不会发送上游；重复请求不重复消费；上传未完成的另一条不拖住已就绪条目。
- 重启前已发送/未发送任务区分正确；删除状态阻止新调度并与 05 的迟到结果清理联动。
- 无账号、额度、超时、参考图读取及程序异常均有真实分类与详情，不泄漏密钥且不反复逐图弹窗。
