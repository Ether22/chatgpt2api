# 04 结果、导航与查看器

状态：待实施，仅文档。规格：[R01、R04、R07–R09](../spec.md)。依赖：01、02、03；删除操作接入依赖 05。

## 工作范围

- 长 Prompt 默认两行且可展开，保留参考图/任务标识；响应式按行排列图片，逻辑编号稳定。
- 普通、MD、重跑及复用统一按来源条目组织，“条目 → 第 N 次 → 图片”；新轮次不覆盖旧结果，复用不增加层级。
- 名称取 MD 标识/名称或普通 Prompt 本地短名。右导航可折叠、定位最新轮次、精确定位图片并同步手动滚动位置；父组收起也显示当前位置。
- 导航独立滚动且无滚动穿透，底部可达；窄屏用抽屉。未加载目标先取分页再定位，不为未选 MD 条目生成占位。
- 查看器操作移到图片下方；参考图仅下载/关闭，结果图支持本轮成功图逐张下载与删除，不打 ZIP、不下载整个会话。
- 文件名保留任务名称、图片序号及 MD 输出名主体，扩展名用实际格式；展示实际尺寸，不增加与 MD 尺寸差异警告或自动图像变换。
- Delete 打开确认、Enter 确认、Esc 取消；删后切相邻图，最后一张删后关闭。纯 Prompt 隐藏保留原配置。

## 验收

- 不同断点下 1、2、3、4 阅读顺序一致；多次复用仍在同一来源的第 N 次下。
- 几千图分页下准确跨页定位，高亮和折叠位置提示正确，右栏滚动不带动中间。
- 参考图无误删入口；下载只含当前轮成功图，名称与实际格式一致；键盘确认/取消行为正确。
- 同尺寸不一致结果只显示实际值；隐藏 Prompt 后仍可复用完整配置。
