# 05 范围删除与迟到结果清理

状态：待实施，仅文档。规格：[R06、R10、R11](../spec.md)。依赖：01、03。

## 工作范围

- 单图、本轮、单会话、全部历史分别按身份和对象范围删除；会话旁按钮与顶部清空确认清楚说明范围，导入区清空独立。
- 清理关系、原图、缩略图、标签及已配置存储副本；保留其他轮次或当前素材仍引用的文件，最后引用释放才物理清理。
- 确认后立即隐藏并后台清理；取消未启动任务，在途上游不能中止时处理迟到结果，不让旧快照/轮询重新插入记录。
- 删除失败显示真实原因，保留必要重试信息；部分成功不伪造全成功，也不恢复已删除图片的假可用记录。
- 复用既有存储删除能力，修复吞掉 WebDAV 错误的路径；已完成图不做上游取消，批量删除有限并发、集中更新索引/标签，避免逐张全量重写和重复扫描。
- 当前素材、快照和新图库历史仅手动删除；禁止保留天数或低磁盘自动清理，磁盘不足在消费前报告。纯 Prompt 隐藏不触发图片删除。

## 验收

- 四种范围均检查真实文件、标签、缩略图及副本，且不影响其他会话/身份/当前素材的有效引用。
- 生成中删除立即响应，未启动任务不消费、迟到结果自动清理，刷新及轮询不复活。
- 注入副本删除失败能展示原因并重试；本地已完成图批量删除无重复取消/索引全量改写。
- 大批删除记录耗时与 I/O 次数，自动清理配置不能删除受管理历史。
