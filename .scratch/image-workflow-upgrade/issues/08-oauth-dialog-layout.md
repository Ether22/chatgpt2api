# 08 OAuth 弹窗可达性

状态：待实施，仅文档。规格：[R15](../spec.md)。依赖：无。

## 工作范围

- 对 OAuth 导入弹窗设置可视区域内的高度约束，正文可滚动，长授权 URL 不无限撑高，底部提交/取消保持可达。
- 保留完整授权 URL 复制、回调输入、授权状态和既有登录流程；优先局部布局调整，不无故改动所有公共弹窗。
- 兼顾窄屏、低高度窗口、缩放及键盘焦点，不在页面写入截图中的临时授权数据。

## 验收

- 使用长说明和长 URL 检查低高度、窄屏及浏览器缩放，完成导入/取消始终可以点击或通过键盘到达。
- 正文滚动、复制完整 URL、回调输入和焦点切换均正常；检查公共 Dialog 的其他调用不受影响。
