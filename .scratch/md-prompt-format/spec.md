# MD Prompt 包格式适配与提交后关窗

用户要求适配 double-wall-glass-mug-001/prompts.md 的格式，并在点击生成后自动关闭窗口。

- 识别 M01、S01、A01_D、A01_M 等文档标识，条目数量由文档决定。
- 用途作为无标题名称时的展示名称；目标尺寸支持括号中的比例说明。
- 读取条目直属的 text 围栏作为 Prompt，保持正文原样，不拼接文档说明。
- 参考图（按上传顺序）中的顶格编号列表支持 R 编号、文件名、描述与用途，仅按明确文件名和原顺序匹配。
- 保留既有格式、冲突与缺失校验；说明段落不作为生成条目。
- 提交成功且会话接收完成后关闭导入窗口；提交失败显示错误并保留重试与当前素材。
