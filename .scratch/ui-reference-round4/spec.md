## 已核对的事实

- 刷新进度已有从 0 开始的 `total_quota`，统计本批已处理账号；前端当前采用的 `stats.total_quota` 是全池合计，因此一开始包含未刷新账号。
- 当前批次累计会在失败后读取账号已保存额度，网络失败且健康状态未变时可能累计旧值。普通使用且健康正常的额度才属于可消费额度；监控另计，禁用、限流、异常不加入。
- 单个、选中和全部账号复用相同刷新入口；短“刷新”按钮只重读账号列表。密码恢复已有查询新额度的逻辑，但恢复进度尚无批次累计额度字段。
- 参考版 Prompt：整块靠右，手机最大 90%、桌面 82%；正文是无外框的浅灰圆角折叠块，默认首行摘要，展开全文左对齐。轮次信息在上方，复用/删除在下方。
- 参考版图片：图像自身圆角，没有固定灰底；桌面为原比例自然高度的 CSS columns 瀑布流，手机三列。直接复制会改变上一轮已确认的 4 张 2×2、6 张 3×2 和紧凑高度。
- 两版图片下方的结果信息、加入编辑和下载按钮已经接近；当前额外的删除、失败详情、继续等待和重试功能需要保留。
